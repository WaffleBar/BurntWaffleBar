The Mage theme
==============

Retail WoW Mage class identity — Arcane mastery — runic circles, frost crystals, arcane violet-blue energy.

Procedurally drawn micro-menu icons with unique Mage
class props (weapons, emblems, armor) per button.

Pipeline: tools/DrawClassThemeSources.cs + tools/ClassThemeBuilder.cs
  Raw:  source/TheMage_{Name}.png
  Out:  this folder / {Name}.png

Select in /bw → Icon Theme → The Mage.
