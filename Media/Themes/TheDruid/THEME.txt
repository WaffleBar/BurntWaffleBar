The Druid theme
===============

Retail WoW Druid class identity — Nature's balance — living bark, lunar cycles, feral claws, emerald dream.

Procedurally drawn micro-menu icons with unique Druid
class props (weapons, emblems, armor) per button.

Pipeline: tools/DrawClassThemeSources.cs + tools/ClassThemeBuilder.cs
  Raw:  source/TheDruid_{Name}.png
  Out:  this folder / {Name}.png

Select in /bw → Icon Theme → The Druid.
