The Priest theme
================

Retail WoW Priest class identity — Holy light and shadow — sanctified silver, divine radiance, void whispers.

Procedurally drawn micro-menu icons with unique Priest
class props (weapons, emblems, armor) per button.

Pipeline: tools/DrawClassThemeSources.cs + tools/ClassThemeBuilder.cs
  Raw:  source/ThePriest_{Name}.png
  Out:  this folder / {Name}.png

Select in /bw → Icon Theme → The Priest.
