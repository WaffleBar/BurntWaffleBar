The Death Knight theme
======================

Retail WoW Death Knight class identity — Unholy frost — runeforged blades, blood runes, Lich King ice, Scourge steel.

Procedurally drawn micro-menu icons with unique Death Knight
class props (weapons, emblems, armor) per button.

Pipeline: tools/DrawClassThemeSources.cs + tools/ClassThemeBuilder.cs
  Raw:  source/TheDeathKnight_{Name}.png
  Out:  this folder / {Name}.png

Select in /bw → Icon Theme → The Death Knight.
