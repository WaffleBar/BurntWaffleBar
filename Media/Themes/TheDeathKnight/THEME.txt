The Death Knight theme
======================

Retail WoW Death Knight class identity — runeforged steel, frost ice,
bone ivory, blood rune accents (multi-material, NOT monochromatic red).

Source art: AI-generated bespoke icons with four distinct material colors.
Post-processed via tools/ProcessDeathKnightIcons.cs (same color-preserving
pipeline as ProcessPreserveThemeIcons.cs — no harmonization wash).

  Raw:  source/TheDeathKnight_{Name}.png
  Out:  this folder / {Name}.png

Select in /bw → Icon Theme → The Death Knight.
