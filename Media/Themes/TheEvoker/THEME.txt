The Evoker theme
================

Retail WoW Evoker class identity — Dracthyr legacy — bronze hourglass, emerald life, azure breath, dragonflight magic.

Procedurally drawn micro-menu icons with unique Evoker
class props (weapons, emblems, armor) per button.

Pipeline: tools/DrawClassThemeSources.cs + tools/ClassThemeBuilder.cs
  Raw:  source/TheEvoker_{Name}.png
  Out:  this folder / {Name}.png

Select in /bw → Icon Theme → The Evoker.
