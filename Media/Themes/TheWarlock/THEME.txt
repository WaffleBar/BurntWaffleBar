The Warlock theme
=================

Retail WoW Warlock class identity — Fel and shadow — soul shards, demonic contracts, green fel fire, void purple.

Procedurally drawn micro-menu icons with unique Warlock
class props (weapons, emblems, armor) per button.

Pipeline: tools/DrawClassThemeSources.cs + tools/ClassThemeBuilder.cs
  Raw:  source/TheWarlock_{Name}.png
  Out:  this folder / {Name}.png

Select in /bw → Icon Theme → The Warlock.
