The Shaman theme
================

Retail WoW Shaman class identity — Elements unleashed — storm totems, molten lava, tidal blue, ancestral spirits.

Procedurally drawn micro-menu icons with unique Shaman
class props (weapons, emblems, armor) per button.

Pipeline: tools/DrawClassThemeSources.cs + tools/ClassThemeBuilder.cs
  Raw:  source/TheShaman_{Name}.png
  Out:  this folder / {Name}.png

Select in /bw → Icon Theme → The Shaman.
