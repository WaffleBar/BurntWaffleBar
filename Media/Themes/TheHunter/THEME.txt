The Hunter theme
================

Retail WoW Hunter class identity — Wilderness tracker — leather and bone, emerald marksmanship, beast mastery runes.

Procedurally drawn micro-menu icons with unique Hunter
class props (weapons, emblems, armor) per button.

Pipeline: tools/DrawClassThemeSources.cs + tools/ClassThemeBuilder.cs
  Raw:  source/TheHunter_{Name}.png
  Out:  this folder / {Name}.png

Select in /bw → Icon Theme → The Hunter.
