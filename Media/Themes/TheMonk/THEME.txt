The Monk theme
==============

Retail WoW Monk class identity — Inner harmony — jade mists, brew barrels, Pandaren scrolls, chi energy.

Procedurally drawn micro-menu icons with unique Monk
class props (weapons, emblems, armor) per button.

Pipeline: tools/DrawClassThemeSources.cs + tools/ClassThemeBuilder.cs
  Raw:  source/TheMonk_{Name}.png
  Out:  this folder / {Name}.png

Select in /bw → Icon Theme → The Monk.
